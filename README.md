# 一杯手冲的配比卡

填粉重、粉水比、器具、水温 → 算出**壶里该烧多少水**（粉会吸走一部分）、**分段注水时刻表**、**杯里会得到多少克**；
再用你实测的 TDS 或一句味觉，算出下一杯具体改哪一格、改几格。

体验地址：https://xululu0401.github.io/pour-card/

## 它解决的那一个麻烦

按「1:16」冲 15 g 粉配 240 g 水，最后杯里只有 210 g —— 那 30 g 被粉床留住了。
想要**杯里**正好 230 g，壶里到底该烧多少水？本工具先把这笔账算清楚，再给注水时刻表。

## 口径与边界（页面里也写了）

- 吸水留存系数按器具分五档：锥形滤纸 2.0 / 蛋糕杯 2.2 / 法压 1.0 / 爱乐压 0.8 / 意式 1.0（g 水 / g 粉）。**经验值**，不是精确物理常数。
- 平衡区间 18–22 %、浓度区间 1.15–1.45 % 是「常用工作区间」；**本轮未取得可引用的一手来源**，当参考带而不是合格线。
- 不预测口感、不评价豆子、不处理水质；意式只给参考系数，不做流速与压粉诊断。
- 默认场景（中烘水洗豆 15 g / V60）是**虚构示例**，不是实测数据。
